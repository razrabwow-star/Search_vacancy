# Проверки обновления от 5 октября 2026 года

Рабочие источники: Т-Банк, Яндекс, Альфа-Банк, ВТБ, RWB, Авито. Сбер отключён, Chromium и Playwright убраны из зависимостей и Docker-образа.

## Проверки кода

18 тестов unittest прошли. Проверены обработка каждой вакансии при повторном прогоне, стабильные ID, новые события при изменении релевантности, очередь Telegram, сохранение уже полученных вакансий при сбое следующей страницы, московская и удалённая выборки ВТБ, выявление обрезанного каталога, полнота выдачи Авито и исключение аналитиков данных в отделах бизнес-аналитики.

## Живой общий прогон

Тестовый запуск без Telegram, с отдельной SQLite-базой. Все шесть источников завершены со статусом ok, все полученные вакансии записаны в observations. TLS-проверка включена.

| Источник | Проверено уникальных вакансий | Подходит |
|---|---:|---:|
| Т-Банк | 1720 | 7 |
| Яндекс | 836 | 2 |
| Альфа-Банк | 2346 | 21 |
| ВТБ | 509 | 16 |
| RWB | 141 | 15 |
| Авито | 109 | 0 |
| Всего | 5661 | 61 |

ВТБ: число карточек сверено отдельно для Москвы и удалёнки, общие ID объединены. RWB: пройдены обе страницы списка, получены описания аналитических вакансий. Авито: используется полный ответ фильтра, а не сокращённая главная страница; число карточек сверено со счётчиками направлений. На момент проверки подходящих бизнес-/системных аналитиков у Авито не обнаружено; это не постоянное свойство каталога.

Эти числа относятся только к этому прогону и меняются вместе с публикациями работодателей. Для ВТБ обходится московская и удалённая выдача, для остальных — общие каталоги с отбором географии.

## Что требует проверки на сервере

Новый Docker-образ локально не собирался: Docker в этой среде отсутствует. Потребление памяти и сборку нужно проверить на Ubuntu. Реальная доставка Telegram локально не проверялась: токен не передавался, тесты используют имитацию отправки. Существующая база и .env при обновлении не заменяются.
